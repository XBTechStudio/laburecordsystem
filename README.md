# 经营分析系统（xbtech70）

多品牌的数据录入、分析与股东分红系统。界面支持英文、中文、印尼文，右上角切换，每个账号会记住自己的语言。

线上网址：https://70.xbtech.my（pm2 名 `xbtech70`，端口 3070，服务器资料在 `.env`）

## 功能

| 菜单 | 做什么 |
|---|---|
| 经营总览 | 充值、提款、输赢、费用、净利润，比上期；走势图；系统自动提醒（对账差异、亏钱的优惠、流失的高价值玩家、没录数据的品牌…） |
| 数据录入 | 像 Excel 一样的批量表格：可直接从 Excel 粘贴、Enter 换行、新玩家自动建立。充提（选 PG/银行，余额才准）、优惠领取、玩家资料 |
| 交易记录 | 每一笔充值/提款：谁录入的、什么时候录入、手动还是 Excel 导入（哪个文件）；可按日期、类型、PG/银行、录入人、来源筛选，搜索玩家或单号；有合计，可导出 Excel |
| Excel 导入 | 上传任何平台导出的文件，自动对应各列、按状态筛选（例如只要 COMPLETED）、账号只取第一个词、UTC 时间换算、PG/银行为空时改用另一列、没见过的 PG/银行自动建账户、重复导入自动跳过；对应方式可存成模板，之后自动套用；每次导入都能撤销 |
| 报表 | 按日/周/月/品牌/品牌×月，可自选 16 种数据列，可保存给团队用，可导出 Excel |
| 玩家 | 累计充提、评分与等级（规则可在设置里改）、同手机号跨品牌、联系记录 |
| 流失跟进 | 按设定天数分组，价值高的排前面；记录联系、分配客服、避免重复联系 |
| 优惠 | 每个优惠送出多少、领取者之后充提多少、扣优惠后输赢、保留/调整/取消建议 |
| 客服招客 | 每位客服、每个渠道的联系数、回复率、回流人数、回流后充值、每日联系数 |
| PG/银行对账 | 按账户核对余额：系统余额 = 期初余额 + 充值 − 提款 − 手续费（按账户费率）± 转账/存取/扣费；员工填银行/PG 显示的实际余额，马上显示差额，可记为调整或标记已说明；每个账户有逐日明细 |
| 费用与利润 | 自定义费用/收入类别，利润表（各品牌一列） |
| 股东分红 | 股东、各品牌股份（按生效日期保留历史）、每品牌分红规则、先预览再保存的结算、付款记录 |
| 管理 | 品牌（可设币种与汇率）、员工与自定义角色权限、操作记录、系统设置 |

## 本机运行

```bash
npm install
npm run dev          # http://localhost:3170
```

`.env`（不会提交到 Git）需要：

```
DATABASE_URL=mysql://用户:密码@主机:3306/xbtech70?connection_limit=10&connect_timeout=20&pool_timeout=30
AUTH_SECRET=随机长字符串
ADMIN_PASSWORD=第一次建立 admin 账号用的密码
DEMO_PASSWORD=示范员工账号的密码
SSH_HOST / SSH_PORT / SSH_USER / SSH_PASSWORD / FTP_BASE_PATH / PM2_APP_NAME   # 部署用
```

## 数据库

```bash
npm run db:push      # 按 prisma/schema.prisma 建表/更新表结构
npm run db:seed      # 建默认角色、admin 账号、默认费用类别（重复执行也安全）
npm run db:seed -- --reset-roles   # 另外把 5 个内置角色的权限恢复成默认值
```

## 示范数据

```bash
npm run demo:load            # 3 个品牌、近 700 位玩家、两个多月的充提、流水、优惠、客服记录、股东
npm run demo:clear -- --yes  # 清空所有业务数据（保留 admin、角色、设置、类别、导入模板）
```

**正式交给客户使用前，记得执行 `demo:clear`。**

## 翻译

所有界面文字写成英文，翻译在 `lib/i18n/strings-*.json`（每行：英文、中文、印尼文）。
新增界面文字后执行下面命令，会列出还没翻译的文字：

```bash
node scripts/i18n-keys.mjs
```

## 权限

- 默认只有**管理员**能修改或删除已保存的数据（充提、优惠领取、费用、对账、客服记录、导入撤销等）；管理层、主管和员工只能查看和新增。
- 角色在“员工与权限”里可以自己调整：某个模块给“完全”，那个角色就能改/删这个模块的数据。
- 系统设置 → 常规 →“员工保存后可修改自己记录的时间（分钟）”：默认 0 = 不允许；例如填 10，员工保存后 10 分钟内可以改自己打错的记录。
- 每一笔充提、优惠领取、费用都记录录入人；所有新增、修改、删除都在“操作记录”里。

## 其他说明

- 所有日期按马来西亚/新加坡时间（UTC+8）计算。
- 金额按品牌自己的币种保存；选“全部品牌”时按各品牌汇率换算成基础货币（系统设置 → 常规）。
- 员工被停用后会立即被踢下线；登录失败 5 次会锁 10 分钟。
