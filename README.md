# 经营分析系统（xbtech70）

多品牌的数据录入、分析与股东分红系统。界面支持英文、中文、印尼文，右上角切换，每个账号会记住自己的语言。

线上网址：https://70.xbtech.my（pm2 名 `xbtech70`，端口 3070，服务器资料在 `.env`）

## 功能

| 菜单 | 做什么 |
|---|---|
| 经营总览 | 充值、提款、输赢、费用、净利润，比上期；走势图；系统自动提醒（对账差异、亏钱的优惠、流失的高价值玩家、没录数据的品牌…） |
| 数据录入 | 像 Excel 一样的批量表格：可直接从 Excel 粘贴、Enter 换行、新玩家自动建立。充提（选 PG/银行，余额才准）、优惠领取、玩家资料 |
| 交易记录 | 每一笔充值/提款：谁录入的、什么时候录入、手动还是 Excel 导入（哪个文件）；可按日期、类型、PG/银行、录入人、来源筛选，搜索玩家或单号；有合计，可导出 Excel |
| Excel 导入 | 上传任何平台导出的文件，自动对应各列、按状态筛选（例如只要 COMPLETED）、账号只取第一个词、UTC 时间换算、PG/银行为空时改用另一列、没见过的 PG/银行自动建账户、重复导入自动跳过；对应方式可存成模板，之后自动套用；每次导入都能撤销 |
| 报表 | 按日/周/月/品牌/品牌×月，可自选 16 种数据列，可保存给团队用，可导出 Excel |
| 玩家 | 累计充提、评分与等级（规则可在设置里改）、同手机号跨品牌、联系记录 |
| 流失跟进 | 按设定天数分组，价值高的排前面；记录联系（含发送的文案，可选常用文案）、跟进次数、需要再次跟进的筛选、分配客服、避免重复联系 |
| 优惠 | 每个优惠送出多少、领取者之后充提多少、扣优惠后输赢、保留/调整/取消建议；可为每个优惠设领取条件（见下面“优惠达标追踪”），点优惠名称看每个玩家的进度 |
| 跟进提醒 | 快达标、奖金可领、奖金快过期、已召回、需要再次跟进的玩家；右上角铃铛显示数量，新提醒会弹出（可设提示音）；记录联系后该玩家的提醒自动关闭 |
| 客服招客 | 每位客服、每个品牌、每个渠道的联系数、回复率、回流人数、回流后充值、每日联系数 |
| PG/银行对账 | 按账户核对余额：系统余额 = 期初余额 + 充值 − 提款 − 手续费（按账户费率）± 转账/存取/扣费；员工填银行/PG 显示的实际余额，马上显示差额，可记为调整或标记已说明；每个账户有逐日明细 |
| 逐笔对账 | 每个 PG/银行账户可以填它自己的对账单链接（例如 xtechmail 的 Bill 页）。系统每 15 分钟自动读取，把对账单上每一笔入款/出款和系统里的充值/提款逐笔配对，列出：钱收到了但系统没记录、系统有记录但没收到钱、已出款但系统没记录、系统有记录但没出款；可标记“已核对”并写备注；昨天对不上的会出现在经营总览提醒 |
| 费用与利润 | 自定义费用/收入类别，利润表（各品牌一列） |
| 股东分红 | 股东、各品牌股份（按生效日期保留历史）、每品牌分红规则、先预览再保存的结算、付款记录 |
| 管理 | 品牌（可设币种与汇率）、员工与自定义角色权限、操作记录、系统设置 |

## 本机运行

```bash
npm install
npm run dev          # http://localhost:3170
```

`.env`（不会提交到 Git）需要：

```
DATABASE_URL=mysql://用户:密码@主机:3306/xbtech70?connection_limit=10&connect_timeout=20&pool_timeout=30
AUTH_SECRET=随机长字符串
ADMIN_PASSWORD=第一次建立 admin 账号用的密码
DEMO_PASSWORD=示范员工账号的密码
SSH_HOST / SSH_PORT / SSH_USER / SSH_PASSWORD / FTP_BASE_PATH / PM2_APP_NAME   # 部署用
```

## 数据库

```bash
npm run db:push      # 按 prisma/schema.prisma 建表/更新表结构
npm run db:seed      # 建默认角色、admin 账号、默认费用类别（重复执行也安全）
npm run db:seed -- --reset-roles   # 另外把 5 个内置角色的权限恢复成默认值
```

## 示范数据

```bash
npm run demo:load            # 3 个品牌、近 700 位玩家、两个多月的充提、流水、优惠、客服记录、股东
```

## 钱庄买卖、结算手续费、同行互借

- 钱庄：在“PG / 银行对账”点“钱庄”，选账户、卖出或买入、填金额和汇率（1 外币 = 多少本币），系统自动换算对方币种。如果外币进出的也是系统里的账户（例如 USDT 钱包），选上它，两边余额一起变。
- 结算手续费：PG 转到银行时在“转账 / 结算手续费”填手续费，系统单独记成一行“结算手续费”；账户页显示所选期间的结算手续费合计。也可以在“其他变动”里单独记。
- 同行互借：对账页的“同行互借”分页记录借出、收回、借入、还款，每笔都会算进所用账户的余额；上面的表列出每个同行还欠我们多少、我们还欠多少。

## 逐笔对账（对账单链接）

- 在“PG / 银行对账 → 余额对账”打开账户，在账户设定里贴上它的对账单链接（https://…）并保存，系统会马上读一次今天的。
- 正式环境里系统每 15 分钟自动读取今天的对账单（凌晨 6 点前也补读昨天的）。本机开发不会自动读，用页面上的“立即读取”。不想自动读时，在 `.env` 加 `STATEMENT_SYNC=off`。
- 配对规则：金额完全相同、时间相差不超过 N 分钟（系统设置 → 优惠与对账，默认 30）算同一笔；金额相同时，对账单上的名字和玩家真名一致的优先。对账单上付出又退回的两笔会互相抵消。
- Excel 导入时如果勾选“只取第一个词”当账号，后面的真名会自动存进玩家姓名，用来配对名字。
- 目前支持的对账单格式：xtechmail 的 Bill 页（`/g/…`，按 `?d=日期` 换天）。其他格式的页面需要另外加读取方式。

## 权限

- 默认只有**管理员**能修改或删除已保存的数据（充提、优惠领取、费用、对账、客服记录、导入撤销等）；管理层、主管和员工只能查看和新增。
- 角色在“员工与权限”里可以自己调整：某个模块给“完全”，那个角色就能改/删这个模块的数据。
- 系统设置 → 常规 →“员工保存后可修改自己记录的时间（分钟）”：默认 0 = 不允许；例如填 10，员工保存后 10 分钟内可以改自己打错的记录。
- 每一笔充提、优惠领取、费用都记录录入人；所有新增、修改、删除都在“操作记录”里。

## 其他说明

- 所有日期按马来西亚/新加坡时间（UTC+8）计算。
- 金额按品牌自己的币种保存；选“全部品牌”时按各品牌汇率换算成基础货币（系统设置 → 常规）。
- 员工被停用后会立即被踢下线；登录失败 5 次会锁 10 分钟。

## 优惠达标追踪

- 在“优惠”页点某个优惠的“条件”，勾“追踪这个优惠”，可以先点一个例子再改。
- 可设：周期（每日 / 每周 / 每月 / 整个活动）、开始和结束日期、按累计金额或充值次数（每笔最低金额，一笔大额只算一次）或两者都要、多档奖金（固定金额或充值 %，可设上限）、叠加或只送最高一档、奖金在下个周期发（例如每月 VIP 按上个月）、只限某些玩家等级、达到下一档百分之几或只差多少时提醒、客服联系后隔几小时再提醒、领取期限（不限期 / 到周期结束 / 达标后几小时）和过期前几小时提醒。
- “设置 → 提醒”：每天从几点开始算、每周从哪天开始、只提醒最接近的优惠还是全部、通知负责客服还是品牌所有人、哪些角色接收、弹窗、提示音、检查间隔、召回通知。
- “设置 → 流失与客服”：几天后再次跟进、算成功召回的最低充值、常用文案。
- 每次录入、修改、删除、导入或撤销充值后，系统马上重新计算这些玩家的进度；时间到的事（下个周期的奖金、快过期、再次跟进、周期结束关闭提醒）在打开页面时每分钟检查一次。
- 录入或导入优惠领取时，会自动对上这个玩家还没领的奖金；在“跟进提醒”页也可以直接点“已领取”。

## Lucky Box

用于玩家赢了不能直接提的分数（例如 Daily FREE）。平台上的加分、扣分由客服手动做，系统负责记账和判断什么时候可以放回。

- 存入：客服先在平台上扣掉玩家的分数，再到“数据录入 → Lucky Box”录入（或 Excel 导入，类型选 Lucky Box）。输入新的优惠名称会自动建成 Lucky Box 优惠。
- 释放条件：“优惠”页或“Lucky Box”页点“Lucky Box / 修改”。可设：提款时净赢至少多少（净赢 = 这次提款 − 上次提款以来的充值）、存入后累计充值至少多少、每次最多放出多少（留空 = 一次全部）、几天后过期、是否通知客服。两个金额都留空 = 只能手动释放。
- 每次录入、修改、删除充值或提款后系统马上检查；达到条件就在“跟进提醒”出现“Lucky Box 可释放”并弹窗。客服在平台上加回分数后，在提醒或“Lucky Box”页点“释放”。
- 释放会同时记成这个优惠的一笔领取，所以算进优惠成本和利润。删除这笔领取，释放也会一起删除。
- 过期在打开页面时每分钟检查一次，先存入的先过期。
- 权限模块“Lucky Box”：查看 / 可新增（记录释放）/ 完全（删除记录）。旧角色没设过的话，按“跟进提醒”的权限给。
